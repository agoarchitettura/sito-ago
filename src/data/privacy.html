Titolare del trattamento

Ago Architettura STP Srl, via Roma 211, 62100 Macerata (MC), P.IVA 01967260439 — info@ago.archi.

Quali dati Google usa Hal

  • Gmail (lettura) — i messaggi ricevuti dalla casella hal.novemilia@gmail.com, per riconoscere le richieste dei soci e degli indirizzi autorizzati;
  • Gmail (invio) — per rispondere al mittente e inviare i riepiloghi interni;
  • Google Calendar (eventi) — per leggere e creare eventi/scadenze sul calendario dello studio.

Finalità

I dati servono solo a eseguire le richieste di lavoro dello studio (bozze di documenti di commessa, risposte, scadenze). Non sono usati per pubblicità, profilazione o altre finalità, non sono venduti né ceduti a terzi.

Dove sono trattati

Su un server interno dello studio. Il testo delle richieste può essere elaborato da un servizio di intelligenza artificiale (Anthropic, modelli Claude) solo per eseguire la richiesta stessa; non è usato per addestrare modelli. Le credenziali di accesso sono conservate sul server dello studio con accesso riservato.

Conservazione

I registri tecnici sono conservati per il tempo necessario al funzionamento e al controllo del servizio; i documenti prodotti seguono i tempi di conservazione degli archivi di commessa dello studio.

Uso limitato (Google API Services User Data Policy)

L'uso e il trasferimento ad altre applicazioni delle informazioni ricevute dalle API Google rispettano la Google API Services User Data Policy, inclusi i requisiti di Uso limitato (Limited Use).

Diritti dell'interessato

Accesso, rettifica, cancellazione, limitazione, opposizione e portabilità (artt. 15-22 Reg. UE 2016/679) scrivendo a info@ago.archi; reclamo al Garante per la protezione dei dati personali. L'accesso di Hal all'account Google si può revocare in ogni momento da myaccount.google.com/permissions.

English summary

Hal is an internal application of Ago Architettura STP Srl (controller, contact info@ago.archi). It uses Gmail read and send scopes and Google Calendar events scope only to process work requests sent to the studio mailbox, reply to them and manage studio deadlines. Data is processed on the studio's own server; request text may be processed by an AI provider (Anthropic Claude) solely to fulfil the request and is not used for model training. Data is never sold, shared for advertising or used for any other purpose. Hal's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. GDPR rights can be exercised at info@ago.archi; access can be revoked at myaccount.google.com/permissions.
